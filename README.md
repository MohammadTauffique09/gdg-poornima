# GDG on Campus Poornima University: website

A frontend-only website (HTML, CSS, JavaScript). No build step, no dependencies.

## Run locally
Open `index.html` in a browser.

## Edit content
Everything you will want to change is at the top of `script.js`:
- `CONFIG.whatsappUrl`: paste the WhatsApp group invite link (the button stays hidden until you do)
- `TRACKS`: track descriptions and code snippets
- `EVENTS`: event cards and dates

## Publish on GitHub Pages (free live link)
1. Create a new public repository on GitHub and upload all files from this folder.
2. Repository Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
3. After about a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Submit the repository URL and the live link in the form.
